# Claude 账号防封与付款完整流程（定版）

> 定版：2026-10-20 定级，2026-10-23 补时区与 KYC 执行细则。
> 一句话原则：先在最终出口上把环境养稳，再付费；全程低频、一致、不折腾。

## 背景结论（先认清，再动手）

- 大陆 / 香港 / 澳门都是 Claude 不支持的地区，使用本身就带封号风险，违规终止不退款；其他原因退款按比例。
- 最好的资产是干净的住宅出口：Verizon Business 静态住宅 IP，经 RackNerd 前置链式转发。机场共享节点和机房 IP 直连风险最高；VPS 直装已出局——唯一可接受的变体是 VPS 出站全部走 Verizon socks5 并带 kill-switch。
- 付费 Pro 极可能触发 Stripe + Anthropic 全量复审，大陆卡是最大的风险因子。

## 步骤一：账号——保留旧号，不开新号

- 此前已用一条美区 ISP IP 注册过一个账号（非 Verizon 静态 IP，那条线路与账号详情未知）。默认保留旧账号，不另开新号：多开账号本身就是封号触发器，存活的老注册是资产。
- 那条 ISP 线路若仍干净，就别迁移；若已脏，单向迁移到 Verizon 出口，轻度养号几天再付费。绝不在两个 IP 之间来回跳。
- 只有四种情况才弃号重开：老账号已被封 / 被标、注册在脏 IP 上、账号不完全在自己控制下、登录历史已污染。

## 步骤二：环境——本地 Win11 + 链式出口

- 本地 Win11，桌面端 / CLI 为主力，配 v2rayN TUN 模式。主力工具定为 Claude Code + Design。
- 时区跟随最终出口一次钉死，永不反复。兼职路线②的钉法：
  - 系统时区留北京，Claude 进程单独用 `TZ=America/New_York` 从脚本启动；桌面版关掉自启，只从脚本启动。
  - Claude 专用 Chrome Profile 把 en-US 置顶。注意：Chrome 在 Windows 上不吃 TZ 变量，网页版时区仍报北京，所以网页版只作登录 / OAuth 与少量使用，主力放 CLI + 桌面版。
  - 验收标准：脚本启动的 CLI 显示美东时间（EST）。
  - 配套：Windows 区域设 United States、浏览器语言 en-US 优先、自动校时打开、关掉自动设置时区与定位，不用 JS 时区伪装。

## 步骤三：付款——顺序和铁律

付款方式优先级（从优到次）：

1. **iOS + 礼品卡**：已有美区 Apple ID；只在官方店购买、留好小票、分批兑换。灰卡有风险，不碰。
2. **Starryblu**：SG BIN 万事达借记卡，大陆护照 + 手机号可开；作备用卡，只走官方渠道。
3. **Bybit**：已有账户可用；不要为了这件事新开 Bybit 卡。
4. 大陆卡（风险因子最大，尽量不用）。
5. US PayPal（网页端只收卡，排最后）。

价格参考（iOS 价）：Pro 年付 $214.99；Max 5x $124.99/月、20x $249.99/月（网页价 $100 / $200）。

铁律：

- 先月付 Pro $20 验证稳定性和用量，频繁撞限额再升 Max 5x；未验证稳定前不上 $100–200 的档。
- 拒卡不要反复重试。
- 出问题先申诉，绝不 chargeback。
- 退款只走 Apple，且须单独取消订阅；退款退回美区 USD 余额，约 48 小时，退不回人民币。不要重复薅退款。

## 步骤四：KYC 弹窗出现时怎么办

背景：Anthropic 自 2026-04 起经 Persona 做选择性验证，要实体证件原件 + 活体自拍，不接受复印件 / 扫描 / 数字 ID。典型触发点：升 Max、高频使用、被风控标记；VPN / 位置与声明地址不符是典型情形。Persona 接受中国护照（查人证一致，不查居住地），但验证通过后仍可因在不支持地区使用被封；且提交真实身份是单向门——被封后换邮箱重开的空间大减。

执行细则：

1. 维持 Pro、不跳 Max，低频起步，尽量不触发。
2. 真弹出来时先截图，别当场交材料，回来商量后再决定。
3. 注册名必须与证件拼音一致（这一步在注册时就要对齐）。
4. 验证时用链式出口的浏览器、关定位；手机扫码要在同一出口的 WiFi 下、关蜂窝、拒绝定位授权。
5. 始终保持一致：IP、时区、语言、账单国家、声明地址，五样对得上。

## 踩坑记录

- **多开账号 = 自找封号**：新号没有历史积累，还多一个触发器；老号活着就是资产。
- **付款方式比金额更重要**：大陆卡是全量复审里最大的风险因子，宁可用礼品卡绕开。
- **时区反复横跳是大忌**：钉死一次就不要再改；网页版时区报北京是 Chrome 的固有限制，不是配置错误，别为它反复折腾。
- **KYC 是单向门**：交了真实身份就回不去了，所以策略是"不触发"而不是"准备好材料随时交"。
