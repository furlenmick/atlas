# Cloady 免费档部署 Xray 链式节点（定版）

> 状态：2026-11-24 部署完成，LIVE。
> 定位：免费小流量节点，出站经 Cliproxy 住宅代理。免费档月出站流量 10 GB（官方口径），别当大流量主力。

## 成果形态（现在跑着的版本）

- 平台：cloady.com，登录靠邮箱验证码；Workspace 为 ***，FREE 档，区域 usw1（美西）。
- 当前应用名：`dockerfile`，域名 `***`。
- Xray 版本 26.11.9，监听 :3000。未绑卡、未付款。
- 出站结构：本地 → Cloady → Cliproxy SOCKS5 → 目标。直连出站已去掉，代理挂了就断（fail-closed），不会裸奔。
- UUID 与 WS 路径沿用旧配置不变。

## 部署流程（照着走能复现）

1. 在 Cloady 建应用，规格选免费档，区域 usw1。
2. 上传带 Dockerfile 的 Xray 配置：监听 :3000，入站 VLESS + WS。
3. 配置出站只保留一条：Cliproxy SOCKS5（粘性会话 ***，t-120）。删掉直连出站，保证 fail-closed。
4. 部署前逐项核对配置：**特别是密码栏不能为空**（见踩坑）。
5. 部署完成后验收两件事：
   - 用第二个 Xray 实例经该出站取 example.com，应成功返回。
   - WS 握手应返回 101。

## 踩坑记录（这篇的重点）

- **旧应用删了，域名就失效**：旧应用 `xray`（域名 ***）已于 2026-11-24 按决定删除，旧链接不要再用。
- **上传类应用没有"替换源码"入口**：想换代码只能新建应用；"Deploy now" 只是用旧文件重建，点了没变化不要奇怪。
- **免费额度被第一个应用占满**：第二个应用即使选最小规格也要 $4.25/月且必须绑卡。先删旧应用再建新的，才走得通免费路线。
- **改配置把密码栏写空 → 部署报错**：换 sid 改配置时曾把密码栏清空导致报错，重建才通。教训：改完配置先核对密码栏非空，再点部署。
- **"总是超时"不在服务器端**：用户报超时后做过服务器端诊断——无异常，手机的真实流量一直在走 Cliproxy 出站。结论：超时既不在 Cloady 也不在 Cliproxy 会话，要在手机端按具体目标复现，不要在服务器上瞎改。
- **测速地址的 403 不代表代理坏了**：直连测试里 SOCKS5 / HTTP 测速地址经此出口分别回 HTTP / 403，那是测速地址自身的表现，不等于代理不可用。验收要用真实目标（如 example.com）和 WS 握手，不要只看测速站。
