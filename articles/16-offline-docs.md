# X 长文 → 离线学习文档：完整流程（定版）

## 定版流程

1. **抓原文**：在浏览器里打开原帖，抓全文和全部配图，记下原文链接、作者、页面时间（页面时间前后不一致时按原样记录，不替作者选一个）。
2. **定形式：写学习笔记，不做全文翻译**（原因见踩坑）。用自己的话重写：讲清结构、核心机制、关键数字和账、例子想说明什么、检查清单要点；想法和数字归原文，表达是自己的。
3. **配图本地化**：配图全部下载到本地 `images/` 文件夹，正文按原文顺序引用本地文件，不放远程图片链接——解压后断网也能打开。
4. **交付形态**：
   - Markdown 离线包：`.md` + `images/` 一起打包，打开 md 即可读。
   - 要预览效果时再做 HTML 版：衬线标题、侧边目录、阅读进度条；关键数字做对比卡片（如 $0.0049 对 $0.000084、58 倍）；手机上表格自动堆叠；支持深色模式。

## 踩坑记录（这篇的重点）

- **"公开能看" ≠ "可以全文复制"**：作者发在 X 上免费公开，版权仍归作者。把整篇长文逐句翻译、排版成文档，本质是把整部作品换种语言复制一份——不管署不署名、不管是否商用，这一步都不能做。能做的是：链接 + 概要，或用自己的话重写成学习文档；直接引用不能超过 50 个词。
- **不要先承诺再改口**：这次最初答应了"抓全文、翻译成中文"，后来才改口只给概要，前后不一致——教训是动手前先把形式定死（第 2 步），再开工。
- **"离线"就要真离线**：第一版把图片链接放进文档，那不叫离线版。图片必须下载到本地并用相对路径引用，交付前断网自检一遍。
- **概要太薄也不行**：只有几段的概要不够用，定版的学习笔记要把结构、数字、例子、清单都写全，读完笔记应能复述原文的完整思路。
